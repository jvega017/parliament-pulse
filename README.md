# Parliament Pulse

Policy intelligence dashboard for the Australian Parliament. Built by Prometheus Policy Lab.

## What it does

A Cloudflare Worker (`workers/aph-proxy`) polls the configured official APH RSS
feeds every 30 minutes, archives each item to D1, scores it server-side with a
deterministic engine, and serves the result to the frontend as one composed
`GET /state` response in which every block declares its provenance (`live`,
`derived` or `fixture`). A `fixture` block is always empty and carries a `note`
saying why; the frontend shows an honest empty state for it, never sample
content. The deployed frontend is the separate
`Claude-Workspace/03_Projects/parliament-pulse` repository.

## Local development

Node is pinned by `.node-version` and pnpm by `packageManager` in `package.json`.

```bash
pnpm install
pnpm --filter aph-proxy typecheck
pnpm --filter aph-proxy test
pnpm dev:worker          # wrangler dev --env dev on http://127.0.0.1:8787
```

## Deployment

- **Worker**: deployed only by the `Deploy worker` workflow, after `CI`
  (typecheck, tests, dry-run deploy) passes on a push to `main`. Do not deploy
  by hand from a working copy.
- **D1**: `ARCHIVE` database. Migrations are applied by the owner before the
  deploy that needs them: `wrangler d1 migrations apply parliament-pulse-archive --remote`.
- **KV**: `CACHE` namespace, 5-minute TTL on RSS and `/state` bodies; also holds rate-limit counters.
- **Frontend**: deployed from the separate frontend repository. `deploy-web.yml`
  here is retired and manual-dispatch only.

## Cron schedule (UTC)

| Schedule | Action |
|---|---|
| `*/30 * * * *` | Poll every configured feed, score, archive to D1; re-derive the Senate roster |
| `0 5 * * *` | Ping the 12 reference landing pages (internal link-rot log); prune `job_runs` |
| `0 19 * * *` | QON ingest (zero rows); digest delivery (dormant) |

Every job writes a `job_runs` row with counts, read by `GET /healthz/deep`.
