## Required components (acceptance tests for the completed spec)

- [ ] Finite connection capacity by location, time and connection level (distribution and transmission)
- [ ] Private information: maturity or completion probability
- [ ] Staged demand ramp (anchor PAR-0012), never instantaneous nameplate
- [ ] Requested-versus-drawn utilisation wedge as a modelled object (anchors PAR-0003, PAR-0004)
- [ ] Firm and flexible connection products
- [ ] Developer delay and curtailment costs
- [ ] Augmentation, congestion, reliability and stranding costs
- [ ] Explicit cost incidence
- [ ] Welfare measure per plan section 9.2, transfers separated from resource costs
- [ ] Baseline mechanism plus at least three alternatives from the seven-mechanism set
- [ ] Equilibrium must be capable of generating the observed funnel (PAR-0001 to PAR-0005)
