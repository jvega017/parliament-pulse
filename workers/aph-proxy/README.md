# aph-proxy

Cloudflare Worker that polls the configured Australian Parliament House RSS
feeds into a D1 archive, scores them server-side, and serves the composed
`GET /state` response, plus a CORS-enabled RSS proxy with a 5-minute KV cache.
Which surfaces are live, derived or empty, in production and on the branch, is
recorded in the root `STATUS.md` from dated probes.

## Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| GET | `/healthz` | Liveness: `ok`, version, scoring engine, `resend_wired` |
| GET | `/healthz/deep` | Job-run readiness from `job_runs`: 200 when the last ok poll is within 75 min and each daily job within 26 h, else 503 |
| GET | `/healthz/connectors` | One row per configured feed from `feed_health`, plus `reference_links` (never reported as health) |
| GET | `/state` | Composed signals, connectors, alerts, QONs and threads; every block carries `provenance` and, when empty, a `note` |
| GET | `/archive`, `/archive/analytics`, `/archive/timeline`, `/archive/watchlist-trend` | D1 archive queries |
| GET | `/bills` | Bills Digests rows from the archive |
| GET | `/qons` | QON rows, with `provenance` and a `note` when the table is empty |
| GET | `/members` | Senate roster rows, with `provenance` and a `note` when the table is empty |
| GET | `/alerts`, `/alerts/events` | Alert rules and fired events (rule writes disabled, LB-04) |
| POST | `/digest/subscribe` | Disabled (403, LB-05) until a double opt-in flow exists |
| POST | `/admin/poll-now`, `/admin/backfill-threads` | Require the `x-admin-token` header |
| GET | `/rss?u=` | Proxies one configured feed URL, caches for 5 min, returns XML |
| OPTIONS | any | CORS preflight |

The `u` query param must be exactly one of the feed URLs configured in
`src/jurisdictions.json` (see the table below). Any other path on an APH host,
any extra query string, and any non-APH host is refused.

## Dev

```bash
pnpm --filter aph-proxy dev
# Worker runs on http://127.0.0.1:8787
curl "http://127.0.0.1:8787/healthz"
curl "http://127.0.0.1:8787/rss?u=https%3A%2F%2Fwww.aph.gov.au%2Fsenate%2Frss%2Fnew_inquiries"
```

### Local development environment (`--env dev`)

The `dev` script runs `wrangler dev --env dev`. Production `[vars]` in
`wrangler.toml` allow exactly two origins, `https://parliament-pulse.pages.dev`
and `https://pulse.prometheuspolicylab.com`. The localhost and 127.0.0.1
origins (ports 5173 and 8080) live only in `[env.dev.vars]`, so a local
frontend can call a local Worker:

```bash
npx wrangler dev --env dev
```

A plain `wrangler dev` (no `--env`) uses the production origins and rejects a
localhost frontend at the browser CORS check. Never run
`wrangler deploy --env dev`: it would publish a separate `aph-proxy-dev`
Worker bound to the production KV namespace and D1 database.

## Deploy

Production deploys run only through GitHub Actions: `Deploy worker` runs
after the `CI` workflow (typecheck, tests, dry-run deploy) succeeds on a push
to `main`, and deploys the exact commit CI tested. Do not deploy by hand from
a working copy; that is how production drifted from git (ARCH-02).

First-time setup of a new account (owner-run):

```bash
wrangler kv namespace create CACHE
# Paste the returned id into wrangler.toml under [[kv_namespaces]]
wrangler d1 create parliament-pulse-archive
# Paste the returned id into both ARCHIVE [[d1_databases]] blocks
wrangler d1 migrations apply parliament-pulse-archive --remote
```

## Backup and restore

`RESTORE.md` is the runbook: D1 Time Travel first, then exports
(`pnpm backup:export`, `pnpm backup:export:local`, or the manual `D1 backup`
workflow), restore into a new D1, the manifest count check
(`pnpm backup:verify`), repointing `database_id`, re-applying migrations,
and the dated drill log.

## Config

`wrangler.toml` holds the non-secret config.

- `ALLOWED_ORIGINS`: comma-separated list of origins permitted for CORS. Production allows only the Pages origin and the custom domain; dev origins live in `[env.dev.vars]`.
- KV binding `CACHE`: RSS payload cache with 5-minute TTL.
- D1 binding `ARCHIVE`: database `parliament-pulse-archive`, schema in `migrations/`. Backups and restores: `RESTORE.md`.

## Security

- `/rss` serves only the exact configured feed URLs; redirects are followed only within the allowed APH hosts.
- Per-IP rate limits on the data and health-detail endpoints, held in KV.
- Write endpoints are disabled (alerts, digest subscribe) or require the admin token (`/admin/*`).
- Degraded responses name a failure class only; error text is logged, never served.
- Upstream timeout defaults to Cloudflare's global (about 30 s). No retry loop.
